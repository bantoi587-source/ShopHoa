HOA CO LAU - GITHUB PAGES + SUPABASE V6.1

V6.1 sửa đồng bộ cài đặt giữa máy tính và điện thoại:
- Khi Admin lưu setting trên máy tính, thiết bị khác tự kiểm tra lại mỗi 8 giây.
- Khi quay lại tab / mở lại trang trên điện thoại, setting được tải lại ngay.
- Có hỗ trợ Supabase Realtime nếu bảng site_settings đã bật Realtime; nếu chưa bật thì polling vẫn hoạt động.
- File JS/CSS được tăng version để tránh cache bản V6 cũ.

Upload index.html, styles.css, script.js và thư mục assets vào ROOT của GitHub repository.
Không upload cả thư mục cha.
